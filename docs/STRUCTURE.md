# Как устроен проект

Этот документ нужен тем, кто меняет исходный код. Для обычной установки используйте [руководство](USER-GUIDE.md).

## Где что находится

| Файл или папка | Что внутри |
| --- | --- |
| `x2zapret.exe` | Готовая программа со встроенным .NET и значком X2. Для запуска из репозитория рядом нужны `vendor` и `resources` |
| `src/Zapret.Desktop/` | Окно программы, подписи и подсказки, значок рядом с часами, работа с Windows и запуск модуля обхода |
| `src/Zapret.Core/` | Настройки, профили, выбор рекомендации, обработка результатов, история датчиков и проверка обновлений |
| `tests/Zapret.Tests/` | Автоматические проверки логики, которые запускаются и без окна приложения |
| `resources/catalogs/` | Профили, адреса проверяемых серверов и сведения о включённой версии Flowseal |
| `resources/lists/` | Стандартные списки сайтов, IP-адресов и исключений |
| `vendor/zapret/` | Готовые файлы zapret, WinDivert и Cygwin, служебные пакеты и лицензии |
| `vendor/hardware/` | Сведения об источниках и лицензиях компонентов чтения датчиков |
| `vendor/diskspd/` | Microsoft DiskSpd для теста дисков, его лицензия и сведения для проверки файла |
| `build/` | Сценарии сборки, установщик и список старых файлов, которые можно убрать при обновлении |
| `tools/` | Перенос профилей Flowseal, проверки файлов, подготовка лицензий и публикация версий |
| `legacy/flowseal/` | Исходные консольные инструменты Flowseal и их прежняя инструкция |
| `docs/` | Руководства, описание версий и сведения о лицензиях |
| `artifacts/` | Результаты локальной или автоматической сборки. В Git не сохраняются |
| `x2zapret.slnx` | Файл решения: объединяет приложение, основную логику и тесты |
| `Directory.Build.props` | Общие параметры .NET-проектов и номер версии |
| `global.json` | Выбор версии .NET SDK для сборки |

## Где менять тексты

Основная разметка окна — `src/Zapret.Desktop/MainWindow.xaml`. Сообщения, которые меняются во время работы, находятся в `MainWindow*.xaml.cs`. Общие пояснения к системным ошибкам — в `Runtime/UserMessages.cs`.

Подписи характеристик ПК находятся в `Runtime/PcInfo/Collect.ps1` и связанных сборщиках. Названия разделов и тексты отчёта — в `Zapret.Core/PcInformation.cs`. Сетевые и дисковые отчёты формируются рядом с соответствующими инструментами.

Правила формулировок описаны в [TEXT-STYLE.md](TEXT-STYLE.md). Тексты интерфейса можно менять, но внутренние идентификаторы, команды, имена файлов и ключи сохранённых настроек нужно сохранять.

## Откуда берутся профили

Исходные профили — файлы `legacy/flowseal/general*.bat`. Скрипт `tools/import_flowseal_strategies.py` **читает их как текст и не запускает**. На их основе он создаёт `resources/catalogs/strategies.json`.

Если нужно изменить описание профиля, правьте генератор и создавайте каталог заново. Изменение только готового JSON потеряется при следующем переносе Flowseal и не пройдёт проверку `--check`.

Точное количество профилей зависит от включённой версии Flowseal. Приложение не ограничивает его прежними 22 профилями.

## Исходники и установленная программа

Расположение файлов при установке отличается от репозитория: EXE, библиотеки и каталоги JSON находятся рядом, файлы обхода — в `bin`, списки — в `lists`. Консольные BAT-файлы не нужны графическому приложению и в обычный пакет не входят.

Сценарий сборки упаковывает всё необходимое. Не собирайте рабочую папку вручную из отдельных файлов; используйте команды из [BUILD.md](BUILD.md).

## Совместимость с прежними версиями

Пользовательские данные остаются в `%ProgramData%\Z-zapret`. Некоторые названия в Windows тоже сохраняют старое имя: задача автозапуска, метка владельца службы, ключи установщика и блокировка второго экземпляра программы.

Это сделано намеренно, чтобы обновление находило прежнюю установку и настройки. Переименование этих технических значений — отдельная миграция, а не правка видимого текста.
