# Структура проекта

| Каталог или файл | Назначение |
| --- | --- |
| `src/Zapret.Desktop/` | WPF-интерфейс, трей, интеграция с Windows и управление движком |
| `src/Zapret.Core/` | Настройки, профили, автоподбор, рейтинг и проверка обновлений |
| `tests/Zapret.Tests/` | Регрессионные проверки ядра |
| `resources/catalogs/` | Каталог 22 стратегий и цели сетевых проверок |
| `resources/lists/` | Начальные списки доменов, IP и исключений |
| `vendor/zapret/bin/` | Неизменённые движок, WinDivert, Cygwin и фейковые пакеты |
| `vendor/zapret/licenses/` | Лицензии сторонних компонентов |
| `build/` | Сборка пакетов и NSIS, точный список устаревших файлов |
| `tools/` | Импорт профилей и проверки пакетов/структуры |
| `legacy/flowseal/` | Исходные BAT/PowerShell-инструменты, документация и прежние workflow |
| `docs/` | Руководства, сведения о лицензиях и скриншоты |
| `artifacts/` | Результаты сборки, исключённые из Git |
| `x2zapret.slnx` | Единое решение приложения и тестов |
| `Directory.Build.props` | Общие параметры и версия всех .NET-проектов |
| `global.json` | Выбор SDK |

## Профили

Источники импорта - 22 оригинальных `legacy/flowseal/general*.bat`.
`tools/import_flowseal_strategies.py` читает их как текст и не исполняет сценарии.
Он создаёт `resources/catalogs/strategies.json`; `--check` проверяет совпадение.
При изменении исходных профилей сначала обновите JSON, затем запустите проверки.

## Выпускаемый пакет

Структура исходников и структура установленного приложения различаются.
Сборка кладёт EXE/DLL и каталоги JSON рядом, движок - в `bin`, списки - в `lists`.
BAT-файлы для запуска приложения не используются и в обычный пакет не попадают.

Пользовательские данные остаются в `%ProgramData%\Z-zapret`.
Идентификаторы службы, задачи планировщика, mutex и установщика сохранены
для совместимости с уже установленными версиями. Перестройка репозитория
не требует переноса пользовательских настроек.
