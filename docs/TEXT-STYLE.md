# Как писать тексты x2zapret

Текст должен помогать человеку сделать действие и понять результат без знания устройства сетевых драйверов.

## Основные правила

- Название кнопки отвечает на вопрос «что произойдёт»: «Включить обход», «Сохранить отчёт», «Выбрать папку».
- В пояснении сначала пишите, зачем нужна функция. Техническую реализацию указывайте только там, где она помогает выбору или диагностике.
- В ошибке объясняйте, что не удалось сделать, что сохранено и какой следующий шаг доступен. Не обещайте исправление, которое программа не выполняет.
- Не называйте недоступное значение нулём, отсутствующий ответ — доказанной блокировкой, а работающий модуль — гарантией работы видео и голоса.
- Для новых или меняющихся данных указывайте время проверки. Для измерений подписывайте единицы.
- Различайте закрытие окна и полный выход, работу программы и работу службы Windows, поиск обновления и его установку.
- Используйте одну формулировку для одного действия во вкладках, сообщениях и инструкции.
- Сначала давайте простые шаги. Точные параметры, ограничения и источники выносите в подсказку, отдельный подраздел или техническую инструкцию.

## Принятые названия

| Название | Значение |
| --- | --- |
| Профиль подключения | Готовый набор сетевых настроек; в исходниках и форматах может называться strategy |
| Обход включён | Сетевой модуль запущен; доступность сайтов проверяется отдельно |
| Фоновое подключение | Служба Windows, которая может работать без открытого приложения |
| Значок рядом с часами | Область уведомлений Windows, которую также называют треем |
| Список IP-адресов | Дополнительный список адресов для обхода; техническое имя — IPSet |
| Служебный пакет | Готовый файл данных, используемый обходом; в исходных профилях встречается fake |
| Состояние диска (SMART) | Данные самодиагностики, смысл которых зависит от модели накопителя |
| Модули памяти (SPD) | Характеристики, записанные производителем в оперативную память |

## Что нельзя менять вместе с формулировками

Видимые подписи не равны внутренним именам. Сохраняйте ключи настроек, идентификаторы профилей и категорий, аргументы команд, имена файлов, протоколы обмена, маркеры владения и названия задач Windows, от которых зависит обновление старых установок.

Кодовые обозначения HTTP, TCP, UDP, TLS, SMART, SPD и единицы измерения можно оставить рядом с объяснением. Названия моделей оборудования и показатели, полученные от сторонней библиотеки или прошивки, нельзя выдумывать или переименовывать без понимания их смысла.

Лицензии, авторские уведомления и исходные файлы Flowseal сохраняются в исходном виде. Описания наших действий пишутся отдельно.

После изменения подписи проверьте снимок настоящего окна на небольшом экране. Если текст не помещается, сначала сократите его или перенесите подробности в подсказку, а не увеличивайте минимальный размер окна.
