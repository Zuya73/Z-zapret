# x2zapret для Windows

Приложение для Windows 10 22H2 / Windows 11, x64. Версия 0.2.9.
Все профили закреплённого релиза Flowseal и исходные консольные инструменты сохранены.

Единое чёрно-белое оформление в стиле X2AIR. Переключения тем нет.
Логотип предоставлен владельцем проекта. Папка данных, маркеры службы,
задача планировщика и ключ установщика сохраняют прежние идентификаторы
для обновления пользователей версии Z-zapret без потери настроек.
Ссылки на прежнее имя GitHub остаются совместимыми с перенаправлением после переименования.

## Запуск

Установите `x2zapret-Setup-0.2.9-x64.exe` или распакуйте **весь** portable-архив
и откройте `x2zapret.exe`. Установка .NET отдельно не требуется.
Запуск требует прав администратора: движок использует драйвер WinDivert.
В portable-версии рядом с EXE должны оставаться все DLL, JSON, папки `bin`, `lists`.

1. Откройте «Автоподбор» и запустите быстрый тест.
2. При необходимости выберите полный тест или отдельную стратегию.
3. Примените подтверждённую рекомендацию.
4. На главной странице можно включить автозапуск через службу Windows.

Кнопка закрытия сворачивает приложение в трей (настраивается). Команда «Выход»
в меню трея завершает приложение. Обычный запуск движка прекращается при выходе;
установленная служба продолжает работать. Для её отключения нажмите
«Выключить автозапуск». Чужие службы и процессы не удаляются.

Если уже установлена служба `zapret` другой сборки, приложение покажет конфликт.
Откройте `service.bat` прежней сборки и удалите её службу перед миграцией.

## Что проверяют автотесты

- Быстрый режим: до пяти профилей и основные HTTPS-ресурсы.
- Полный: все профили текущего комплекта, HTTP/1.1, TLS 1.2, TLS 1.3 и справочный ICMP.
- DPI: передача 64 КиБ на цели из открытого каталога dpi-checkers.
- До перебора проверяется соединение без обхода; лучшие три подходящих профиля
  проверяются повторно. Прежнее подключение восстанавливается до применения рекомендации.
- Нужны хотя бы один успешный запрос, не менее 80% успешных поддерживаемых
  проверок и успешные обязательные ресурсы. ICMP не влияет на рейтинг.
- DNS, сертификат, TLS-handshake и неподдерживаемый протокол имеют разные результаты.

Эти тесты подтверждают сетевые запросы, а не воспроизведение YouTube, QUIC/HTTP3,
голосовой чат Discord или отсутствие блокировок во всех приложениях.
Некоторые CDN возвращают 403/404 на корневой адрес: для таких целей эти коды
проверяют только достижимость HTTPS-сервера. Отчёт сохраняет HTTP-код и пояснение.
На Windows 10 системный Schannel может не поддерживать TLS 1.3; такой тест пропускается.

Тесты временно останавливают собственную службу без удаления. Для DPI используются
отдельные копии списков с режимом `any`; пользовательские файлы не меняются.
При отмене выполняется восстановление. После аварийного завершения следующий запуск
читает журнал восстановления; самостоятельный дочерний движок завершается Windows Job Object.

## Настройки и данные

В существующей вкладке «Настройки» доступны переключатели запуска приложения
в трее вместе с Windows и автоматического подключения последней выбранной стратегии.
Второй переключатель работает при включённом первом. Обычное открытие программы
не включает подключение автоматически. Задача планировщика запускается при входе
текущего пользователя с повышенными правами, без сохранения пароля. Удаление приложения
удаляет и эту задачу. Автозапуск движка через службу на главной странице — отдельная настройка.

Переключатель «Автообновление» включает проверку стабильных релизов этого форка
при запуске и каждые 6 часов. Проверку можно вызвать вручную. При обнаружении версии
появятся уведомление и кнопка установки; скачивание и установка требуют подтверждения.
Перед запуском установщика проверяются размер и SHA256 файла из GitHub Releases.
Отмена или повреждённая загрузка не запускает установщик. Настройки и списки сохраняются;
на время установки приложение и подключение останавливаются. После установки откройте
приложение через последний шаг мастера. Portable-сборка обновляется через установщик.

Данные находятся в `%ProgramData%\Z-zapret`:

- `settings.json` — настройки;
- `lists` — пользовательские списки и актуальный IPSet;
- `results` — JSON-отчёты;
- `logs` — журнал;
- `hosts-backups` — резервные копии hosts;
- `test-recovery.json` — журнал незавершённой проверки, если она была прервана.

Списки и фейковые пакеты можно менять через настройки. Пользовательские IP добавляются
к списку в режиме `loaded`; обновление IPSet их не стирает.
Обновление hosts заменяет только блок `BEGIN Z-ZAPRET` / `END Z-ZAPRET`, сохраняя другие
записи. Перед изменением создаётся копия. DNS и антивирус автоматически не меняются.
Старые BAT-инструменты вынесены из приложения в отдельный архив. Его сборка описана в [LEGACY.md](https://github.com/Zuya73/x2zapret/blob/main/docs/LEGACY.md).

Удаление приложения отключает его собственную службу и удаляет его блок hosts.
Общий драйвер WinDivert и пользовательские данные автоматически не удаляются.

## Сборка и проверка

Нужны .NET SDK 10 и Windows для запуска GUI/драйвера; ядро тестируется и на Linux.

Подробные команды и требования находятся в [BUILD.md](https://github.com/Zuya73/x2zapret/blob/main/docs/BUILD.md).


Сборка GitHub Actions компилирует приложение, запускает регрессионные проверки,
проверяет синтаксис исходного PowerShell, рендерит интерфейс без запуска драйвера
и собирает portable ZIP и установщик. Готовые файлы находятся в артефакте `x2zapret-Windows-x64`.

Перед стабильным выпуском нужны реальные проверки на Windows 10 и 11:
драйвер, подключение на нескольких сетях, служба после перезагрузки, отмена теста,
закрытие приложения во время теста, восстановление после сбоя, обновление и удаление.
Графический smoke-тест не заменяет проверки драйвера и работы провайдера.

Сборка не подписана сертификатом издателя. SmartScreen может запрашивать подтверждение.
Проверка манифеста обнаруживает повреждение упакованных бинарников; она не заменяет
цифровую подпись издателя. Сравнивайте SHA256 сборок с опубликованными суммами.

Оригинальная документация Flowseal сохранена в [legacy/flowseal/README.md](https://github.com/Zuya73/x2zapret/blob/main/legacy/flowseal/README.md).

## Публикация обновления

Версия задаётся в `Directory.Build.props`. После успешной сборки и проверок main
workflow автоматически публикует стабильный GitHub Release с тегом `desktop-v<версия>`,
установщиком и portable ZIP. Повторная сборка той же версии не заменяет выпущенные
файлы. Изменение EXE в main без опубликованного релиза клиенту не видно. Автообновление учитывает только
стабильные релизы `desktop-v*` с более новой версией, установщиком с ожидаемым
именем и полем `digest` SHA256 в API GitHub. Исходные релизы Flowseal и предварительные
версии не предлагаются пользователям как обновления приложения.

## X2 Tools: выключение по таймеру

Откройте X2 Tools, задайте часы и минуты и нажмите «Запустить таймер».
Доступны быстрые значения 15/30 минут и 1/2 часа. Допустимый диапазон - от
1 минуты до 7 дней. В карточке видны оставшееся время и точная дата выключения.
До начала выключения нажмите «Отменить таймер», чтобы убрать задачу.

Таймер принадлежит текущему пользователю Windows и работает после закрытия
или обновления x2zapret. При повторном открытии состояние восстанавливается
из планировщика Windows. При удалении приложения его собственный таймер удаляется.
Задачи других программ не изменяются.

Выключение не принудительное: несохранённые документы могут его задержать.
Пользователь должен оставаться в Windows, а ПК - быть включённым. Таймер не будит
компьютер и не выполняет пропущенное выключение после сна или перезагрузки.

## Обновление компонентов Flowseal

Версия компонентов видна в настройках. Новые движок, профили и стандартные
списки приходят вместе с проверенной версией x2zapret, через обычное обновление.
Ручной запуск BAT-файлов для этого не нужен.

Пользовательские списки сохраняются. Неизменённые стандартные списки обновляются;
если стандартный файл был изменён вручную или обновлением IPSet, активная копия
сохраняется, а новый файл автора записывается рядом с окончанием «.upstream».
При удалении выбранного профиля или фейка из нового комплекта выбирается
доступная замена, прежние настройки сохраняются в settings.json.before-components-update.


## X2 Tools - информация о ПК

В **X2 Tools → Информация о ПК** находятся 18 разделов: обзор, процессор,
оперативная память, плата и BIOS, видеокарты, накопители и разделы, мониторы,
звук, сеть, устройства и драйверы, Windows, программы, процессы, службы,
автозагрузка, датчики и питание. Кнопка «Таймер выключения» открывает прежний инструмент.

При первом открытии категории снимается её состояние. Повторное открытие
показывает сохранённый снимок; «Обновить» собирает новые данные. Поиск работает
по устройству, параметру и видимому значению. Ctrl+C копирует выделенные строки.
Полное значение длинной строки доступно во всплывающей подсказке.
Сбор можно отменить. Закрытие раздела останавливает сбор и текущий мониторинг.

Верхние карточки обновляют загрузку процессора, использование памяти и суммарный
трафик активных адаптеров каждые две секунды, пока раздел открыт. Сетевые показатели
не являются тестом скорости интернета; трафик виртуальных адаптеров может учитываться повторно.

Серийные номера, UUID, адреса сети, имя компьютера, пути процессов и команды
автозапуска скрыты по умолчанию. Флажок «Показывать личные данные и включать их
в отчёт» открывает эти поля. «Сохранить полный отчёт» заново собирает все категории
и сохраняет UTF-8 TXT. Для каждой категории указано время снимка; данные разных
категорий собраны последовательно, а не одновременно. Отключите флажок перед
отправкой отчёта другим людям, если идентификаторы не нужны. Автоматической отправки нет.

Это собственный обзор системы по доступным Windows данным, а не полная замена
всех аппаратных декодеров AIDA64. Раздел информации о ПК не выполняет стресс-тесты; отдельный замер дисков запускается только пользователем. Приложение
не меняет частоты, напряжения или настройки оборудования. Список программ читается
из реестра без Win32_Product и проверки/ремонта MSI-пакетов.

Встроенный мониторинг использует LibreHardwareMonitor 0.9.6. Отдельную программу
запускать не требуется. В категории «Живые датчики и питание» показания обновляются
каждые две секунды, пока страница открыта. Минимум и максимум считаются с начала
сеанса; после ухода из X2 Tools сеанс завершается. Встроенный сборщик работает
в отдельном процессе, который автоматически останавливается при закрытии раздела.

Для CPU, платы и чтения SPD нужен подписанный PawnIO 2.2.0 или новее. Кнопка
«Включить датчики CPU / платы / SPD» скачивает его у официального автора, проверяет
размер, SHA256 и цифровую подпись, затем устанавливает. Для загрузки нужен интернет.
Само приложение, GPU, диски и батарея не требуют этой установки, если их драйверы
отдают данные обычным способом. Более новая установленная версия не заменяется
старой. Если установщик просит перезагрузку, она остаётся за пользователем.
При удалении x2zapret общий PawnIO не удаляется: его могут использовать другие программы.

«SMART / NVMe» показывает доступные атрибуты накопителя: полный целочисленный RAW,
нормализованное текущее/худшее значение и порог, а также показатели температуры,
наработки и ресурса, которые доступны через контроллер. Обновление дисковых данных
ограничено 30 секундами. Отсутствующие показатели не вычисляются. USB-мост, RAID,
виртуальный диск или прошивка могут скрывать часть SMART. RAW и нормализованные
значения нельзя сравнивать напрямую; расшифровка зависит от модели накопителя.

«Память · SPD и тайминги» показывает доступные паспортные тайминги DDR4/DDR5 из SPD
и датчик температуры модуля. Это не измерение текущих настроек контроллера памяти.
Старый обзор модулей по SMBIOS остаётся в «Оперативной памяти». Запись SPD,
применение XMP/EXPO, разгон и управление вентиляторами не выполняются.

Внешние WMI-источники LibreHardwareMonitor / OpenHardwareMonitor по-прежнему
поддерживаются дополнительно. ACPI-зоны подписаны отдельно и не выдаются за CPU.
Программа не меняет настройки защиты Windows ради доступа к датчикам.
Поддержка зависит от модели оборудования: полного покрытия всех декодеров AIDA64
это обновление не обещает. Стресс-тестов CPU/RAM нет. Замер скорости дисков - отдельный инструмент, запускаемый по кнопке.


## X2 Tools - скорость дисков

Откройте **X2 Tools → Скорость дисков**, выберите локальный или съёмный том,
размер временного файла (256 МиБ, 1 ГиБ или 4 ГиБ) и режим. Нажмите «Запустить».
Быстрый режим выполняет восемь замеров по 3 секунды, подробный - три прохода
по 5 секунд для каждого замера. Дополнительно требуется время на подготовку файла.

Доступны SEQ1M Q8T1, SEQ1M Q1T1, RND4K Q32T1 и RND4K Q1T1, каждый отдельно
для чтения и записи. SEQ - последовательные операции по 1 МиБ; RND - случайные
операции по 4 КиБ; Q - глубина очереди; T1 - один поток. Большие числа чтения/записи
показаны в десятичных МБ/с (1 000 000 байт/с). Ниже - IOPS и средняя задержка.
Во всплывающей подсказке доступны задержка P95 худшего прохода и число проходов.
При повторениях средняя скорость считается по общему времени и объёму данных,
а задержка - с весом по числу операций. P95 разных проходов не выдаётся за общий перцентиль.

Движок Microsoft DiskSpd 2.3 уже находится внутри EXE; интернет и дополнительные
драйверы не нужны. Перед запуском встроенный файл проверяется по SHA256.
Программа создаёт новую собственную папку x2zapret-disk-test-<GUID> в корне выбранного
тома и полностью записывает отдельный data.bin случайными данными. Существующие
файлы и физические диски как сырые устройства не используются. Нужно место под
выбранный файл плюс 1 ГиБ свободного резерва; для FAT32 выберите размер меньше 4 ГиБ.

Измерение выполняется без файлового кэша Windows (-Su). Аппаратный кэш накопителя
остаётся штатным. На результат влияют размер файла, заполненность, SLC-кэш SSD,
температура и фоновые копирования; результаты с другими настройками CrystalDiskMark
могут отличаться. Объём фактической записи за временной интервал может превышать
размер файла, поскольку он используется повторно.

«Отменить» завершает только собственный процесс измерения и удаляет временные
данные. После нормального окончания файл и папка также удаляются. Рекурсивное удаление
не применяется: посторонние файлы, добавленные в папку, сохраняются, а сообщение об
остатках попадает в отчёт. При аварийном завершении/отключении питания папка с указанным
префиксом может остаться; такой остаток можно удалить вручную после завершения процесса.

Во время замера новый тест, изменение его параметров и опрос аппаратных датчиков
в этом приложении недоступны. Окно можно свернуть в трей; полный выход отменяет
замер с очисткой. «Сохранить результат» сохраняет UTF-8 TXT, включая частичные
измерения при отмене и сообщения об ошибках/очистке.


## Контроль подключения и восстановление

В обзоре статус движка отделён от доступности сервисов. В диагностике доступны результаты
проверок главных сайтов и CDN Discord / YouTube, а также контрольных сайтов Google / Cloudflare.
HTTPS-ответ не доказывает работу голосового соединения Discord, QUIC или воспроизведения видео.
Неподтверждённый результат не означает, что сервис заблокирован: возможен сбой сайта, DNS или маршрута.

В **Настройки → Контроль подключения** можно отключить фоновые проверки (по умолчанию включены,
каждые 45 секунд при работающем приложении, включая трей). Умное переподключение по умолчанию
выключено и включается отдельно. Оно требует трёх неудачных наблюдений за период от 75 секунд
и ответа хотя бы одного контрольного сайта. После ручного выключения движок не запускается заново.
При потере всей сети стратегии не перебираются. Одна попытка включает исходную и до трёх запасных
стратегий; новая сохраняется только после двух успешных проверок. Если замена не подтверждена,
восстанавливается исходная стратегия. Лимит: 3 попытки за 15 минут, пауза от 2 минут. Бюджет действует
в текущем сеансе приложения. Во время других операций мониторинг и восстановление приостановлены.
Незавершённое восстановление сохраняет журнал для следующего запуска. При полностью закрытом
приложении мониторинг не работает, даже если движок работает как служба.

## X2 Tools → Графики датчиков

Выберите датчик для графика. Доступны CPU / память и показания встроенного аппаратного сборщика;
поддержка конкретных температур, оборотов и напряжений зависит от оборудования и PawnIO.
Опрос - каждые 2 секунды, аппаратный опрос может занимать дольше. Хранится до часа и 1800 точек
на датчик (до 512 датчиков). После пауз линия прерывается. Сбор по умолчанию идёт при открытом
инструменте; флажок записи продолжает его в других вкладках и трее до полного выхода.
Во время тестов и других операций сбор приостановлен. История хранится в памяти; CSV сохраняется вручную.
CSV содержит UTC-время и числовые значения с точкой. Он может включать названия оборудования.

Для выбранного датчика можно сохранить порог в его единицах. При превышении выводятся запись
в журнале и уведомление в трее. Повтор - после снижения значения и нового превышения,
не чаще раза в 5 минут на датчик. Если сбор показаний остановлен, уведомления не проверяются.
Доступность всплывающих уведомлений зависит от настроек Windows.

## X2 Tools → Интернет

**Качество:** внешний домен / IP, шлюз выбранного адаптера, 30 ICMP-пакетов. Средний пинг,
минимум / максимум, потери ICMP-ответов и джиттер (средняя абсолютная разница соседних успешных ответов).
Маршрут - по флажку, до 20 переходов. Отсутствие ICMP-ответов или звёздочки маршрута не доказывают
проблему с пересылкой обычного трафика: оборудование может ограничивать ICMP. Проверка шлюза
не определяет автоматически фактический маршрут к цели: выберите адаптер своей сети.

**Скорость:** реальные последовательные HTTPS-загрузка / отдача до ближайшего узла Cloudflare,
плюс HTTP-задержка без нагрузки и во время передачи. Быстрый режим передаёт до 62 МБ полезных данных,
подробный - до 262 МБ, сетевые накладные расходы учитывайте отдельно. Мелкие блоки увеличиваются,
пока отдельная передача не займёт 3 секунды или не будет достигнут лимит размера. Мбит/с рассчитываются
по полным блокам и времени HTTP-запросов; это оценка одного потока до данного сервиса, а не обещание
максимальной скорости тарифа. Прокси Windows для измерений не используется. Не запускается в фоне.
Отмена сохраняет завершённые результаты; частично отправленный блок может не попасть в счётчик.
При недоступном сервисе выводится ошибка. Отчёт можно сохранить вручную. Сервер Cloudflare видит
ваш публичный IP, как при обычном HTTPS-подключении; учётная запись и личные файлы не передаются.

## X2 Tools → Занятое место

Укажите локальную папку или корень тома и запустите анализ. Отображаются до 100 крупнейших
папок первого уровня и 100 крупнейших файлов. Двойной щелчок по папке запускает анализ внутри неё;
можно подняться выше или показать выбранный объект в проводнике. Инструмент ничего не удаляет.

Считается логический размер доступных файлов. Ссылки / точки подключения, чрезмерная вложенность
и недоступные каталоги пропускаются; жёсткие ссылки могут учитываться повторно. Поэтому сумма
не равна фактически занятому месту на томе. Лимит - 10 минут / 2 млн записей / 10 тыс. групп папок;
отмена или лимит времени оставляют частичный результат. Пропущенные объекты указаны счётчиком.

Методика сервиса измерений: [официальные API Cloudflare Speedtest](https://github.com/cloudflare/speedtest#api-reference).
