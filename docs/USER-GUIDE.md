# Как пользоваться x2zapret

Руководство для версии **0.2.11**. Программа рассчитана на Windows 10 22H2 и Windows 11, 64-разрядные системы.

x2zapret включает обход ограничений с помощью готовых профилей Flowseal. **Профиль** — набор сетевых настроек. Если не знаете, какой выбрать, воспользуйтесь автоподбором.

## Установка и первый запуск

Проще всего скачать установщик со [страницы загрузки](https://github.com/Zuya73/x2zapret/releases/latest): `x2zapret-Setup-0.2.11-x64.exe`. Запустите его и следуйте шагам мастера. Если Windows спросит разрешение администратора, нажмите «Да». Оно нужно для сетевого драйвера обхода.

Можно работать без установки: скачайте `x2zapret-0.2.11-win-x64.zip` и **распакуйте весь архив**. Открывайте `x2zapret.exe` из этой папки. Не переносите EXE отдельно: рядом нужны остальные файлы и папки из архива. .NET отдельно устанавливать не нужно.

В корне репозитория тоже есть готовый `x2zapret.exe`. Для этого варианта скачайте репозиторий целиком через **Code → Download ZIP**, распакуйте и оставьте папки `vendor` и `resources` рядом с EXE.

Программа пока не подписана сертификатом издателя. Windows SmartScreen может показать предупреждение. Проверяйте, что скачали файл со страницы x2zapret, указанной выше. Контрольные суммы файлов находятся там же, в `SHA256SUMS.txt`; это проверка совпадения файла, а не цифровая подпись издателя.

## Как включить обход

1. Откройте **«Автоподбор»**.
2. Оставьте быстрый режим и нажмите **«Начать проверку»**.
3. Дождитесь результата. Во время подбора интернет может ненадолго прерываться.
4. Нажмите **«Включить рекомендованный профиль»**.
5. Проверьте Discord или YouTube: например, начните голосовой разговор или откройте видео.

Затем обход можно включать и отключать кнопкой на странице **«Обзор»**.

Если подходящий профиль не найден, программа покажет, что можно сделать: очистить кэш DNS или сменить DNS, отключить VPN и другие программы обхода, попробовать полный режим. Если без обхода не ответил ни один сервер, она подскажет проверить подключение к интернету. Попробуйте полный режим. Если раньше всё работало, а теперь нет, повторите подбор: провайдер или настройки сети могли измениться.

## Как читать состояние подключения

Программа проверяет две разные вещи:

- **Включён ли обход.** Это означает, что работает его сетевой модуль.
- **Отвечают ли сервисы.** Программа отдельно обращается к серверам Discord и YouTube. Подробные результаты есть в «Диагностике».

Включённый обход не гарантирует доступ к сайту. И наоборот: сайт может отвечать даже без обхода. Успешный запрос к серверу не подтверждает воспроизведение видео, голосовой чат или все способы передачи данных.

Кнопка **«Проверить Discord и YouTube»** на «Обзоре» проверяет их прямо сейчас — результат появится в карточке состояния.

Если результат устарел, программа указывает это рядом со временем проверки. «Интернет не проверен» означает, что не удалось получить подтверждение от контрольных сайтов, а не обязательно полный обрыв связи.

## Автоподбор и ручной выбор профиля

| Режим | Что делает |
| --- | --- |
| **Быстрый** | Проверяет до пяти профилей на основных серверах Discord, YouTube и Google |
| **Полный** | Проверяет все профили из этой версии программы и несколько способов защищённого соединения |
| **Передача данных · DPI** | Дополнительно проверяет обмен тестовыми данными с серверами из каталога dpi-checkers |

Перед подбором проверяется обычное соединение без обхода. До трёх лучших подходящих профилей проверяются повторно. После подбора прежнее подключение восстанавливается; новый профиль включается только по кнопке рекомендации.

Можно включить флажок **«Проверить только выбранный профиль»**. Для ручного выбора откройте **«Профили»**, выберите строку и нажмите **«Выбрать профиль»**. Сам выбор не переключает уже работающее подключение: отключите и снова включите обход, чтобы применить его.

**«Отмена»** останавливает подбор и возвращает прежнее подключение. Завершённые результаты остаются доступными. Если программа аварийно закрылась во время проверки, при следующем запуске она попытается восстановить прежнее состояние.

Кнопка **«Сохранить отчёт»** сохраняет результаты. Текстовый файл удобен для чтения, JSON — для технического разбора.

### Что означают технические результаты

Полный режим проверяет HTTP/1.1, TLS 1.2 и TLS 1.3. Это способы обращения к серверу и защиты соединения. Если Windows не поддерживает один из них, он отмечается как недоступный и не считается успешным.

Профиль рекомендуют, если он прошёл обязательные проверки и не менее 80% поддерживаемых проверок. Обычный пинг не влияет на выбор. Для некоторых серверов файлов ответ 403 или 404 на главную страницу ожидаем: он подтверждает ответ сервера, но не доступ к любому файлу.

Режим DPI использует отдельные временные копии списков и передаёт тестовые данные. Ваши списки сайтов не изменяются. При подборе программа управляет только своим подключением.

## Запуск с Windows, сворачивание и полный выход

В **«Настройках» → «Запуск приложения»** есть два переключателя:

- **«Запускать вместе с Windows в фоне»** — после входа в Windows значок программы появится рядом с часами, без открытия окна.
- **«Автоматически подключаться»** — одновременно с этим запуском включать последний выбранный профиль. Работает при включённом первом переключателе.

После выбора нажмите **«Сохранить автозапуск»**. Обычное открытие программы вручную само по себе не включает обход.

Если включена настройка сворачивания при закрытии окна, крестик оставляет программу работающей рядом с часами. Для полного завершения нажмите правой кнопкой на значок x2zapret и выберите **«Выход»**.

### Фоновое подключение без открытой программы

На странице **«Обзор»** есть отдельная настройка **«Фоновое подключение»**. Она устанавливает службу Windows, которая запускает обход при включении компьютера и может работать после полного выхода из x2zapret.

Это отдельный способ запуска: закрытие приложения не отключает такую службу. Чтобы убрать её, нажмите **«Отключить фоновое подключение»** на странице «Обзор».

Если фоновое подключение не включено, полный выход из программы останавливает её обычный модуль обхода.

## Проверка доступа и умное переподключение

В **«Настройках» → «Контроль подключения»** можно включить или отключить проверку доступности сервисов. По умолчанию она включена: раз в 45 секунд программа обращается к Discord, YouTube и контрольным сайтам Google/Cloudflare. Проверка работает и при сворачивании к значку рядом с часами.

**«Умное переподключение» по умолчанию выключено.** При включении оно может перезапустить обход и попробовать другой профиль, если доступ пропал.

Восстановление начинается после трёх неудачных проверок за период не короче 75 секунд, если хотя бы один контрольный сайт отвечает. Программа пробует текущий и до трёх запасных профилей. Замена сохраняется после двух успешных проверок, пока сам модуль обхода продолжает работать. Если замена не подошла, возвращается прежний профиль.

Между попытками — пауза от двух минут; не более трёх попыток за 15 минут в текущем сеансе программы. После ручного отключения обход не включится сам. Если интернет в целом не подтверждён, профили не перебираются. Во время других операций восстановление приостановлено.

При полном выходе из x2zapret проверки и восстановление прекращаются, даже если служба обхода продолжает работать.

## Обновления программы

Откройте **«Настройки» → «Проверить сейчас»**. Если новая версия доступна, нажмите **«Скачать и установить»** и подтвердите действие.

Переключатель **«Проверять обновления автоматически»** включает поиск новой версии при запуске и каждые 6 часов. Установка всё равно требует вашего подтверждения.

Перед запуском установщика проверяются источник загрузки, размер и контрольная сумма — признак совпадения файла с опубликованным. Повреждённый или недокачанный установщик не запускается. Отменить загрузку можно отдельной кнопкой.

На время обновления программа и обход останавливаются. Настройки и ваши списки сохраняются. После установки откройте программу из последнего окна мастера. Обновление, запущенное из версии без установки, тоже использует установщик.

Профили и основные файлы Flowseal поступают с проверенными обновлениями x2zapret. Программа не устанавливает произвольный выпуск Flowseal поверх себя.

## Диагностика и журнал

В **«Диагностике»** нажмите **«Проверить систему»**. В таблице будет видно, найдены ли нужные файлы и службы Windows, работает ли обход и есть ли возможные конфликты с другими сетевыми программами.

Кнопка **«Проверить доступность сейчас»** обновляет ответы сервисов. Сам факт обнаружения другой программы не доказывает конфликт: смотрите пояснение в строке и проверяйте связь после своих изменений.

Дополнительные действия:

- **Очистить кэш Discord.** Удаляет его временные файлы. Сначала полностью закройте Discord, включая значок рядом с часами.
- **Включить TCP timestamps.** Включает временные метки в сетевых пакетах Windows. Это требуется некоторым профилям; без необходимости менять настройку не нужно.
- **Открыть службы Windows.** Открывает системный список фоновых служб для ручной проверки.

Если найдена другая версия zapret, отключите в ней обход и фоновое подключение. Для прежнего консольного комплекта используйте его меню `service.bat`. x2zapret не удаляет чужие службы и не завершает чужие процессы.

В **«Журнале»** видны действия программы и сообщения об ошибках. Кнопка сохранения создаёт текстовый файл. Перед отправкой другому человеку просмотрите его: в технических сообщениях могут встречаться пути к файлам и адреса.

## Дополнительные настройки и списки сайтов

Если автоподбор работает, обычно эти настройки менять не нужно.

**Список IP-адресов** — дополнительный выбор адресов для обхода. Можно не использовать его, обрабатывать адреса из списка или все IP-адреса. Последний вариант затрагивает больше соединений: после изменения проверяйте обычные сайты и игры.

**TCP и UDP** — два способа передачи данных в сети. Настройки обхода для игр и номера портов нужны для специальных случаев. **Служебные пакеты** — готовые файлы данных для работы обхода; без причины менять их не нужно.

В разделе **«Какие сайты обрабатывать»** доступны списки сайтов и IP-адресов для обхода и исключений. Вводите по одному адресу в строке:

- Для сайта — домен без `https://` и пути, например `example.com`.
- Для IP — адрес, например `192.0.2.1`, или подсеть, например `192.0.2.0/24`.

Сохраните список, затем отключите и снова включите обход. Обновление общего списка IP не стирает ваши дополнительные адреса.

**hosts** — файл Windows, в котором можно вручную задать адреса сайтов. Кнопка обновления добавляет отдельный блок Flowseal и сохраняет резервную копию. Кнопка удаления убирает только записи x2zapret. Остальные записи остаются. DNS и настройки антивируса программа автоматически не меняет.

## X2 Tools: как устроен раздел

Инструменты разделены на четыре группы: **Компьютер** (сведения и датчики), **Диски** (скорость и место), **Интернет** и **Таймер**. У групп «Компьютер» и «Диски» в той же строке появляются вкладки второго уровня.

После проверки диска, соединения или скорости сверху показывается короткий вывод: например, «Обычный SSD» или «Проблема в домашней сети». Подробные цифры остаются ниже.

Значок шестерёнки справа от вкладок включает режим **«Для опытных»**. Он показывает размер и режим теста диска, путь до сервера, подробный замер скорости, сохранение CSV с датчиками и установку драйвера датчиков. Без него используются настройки по умолчанию. Выбор запоминается.

## X2 Tools → О ПК

Здесь можно посмотреть процессор, память, материнскую плату, видеокарту, диски, мониторы, звук, сеть, устройства, Windows, программы, процессы, службы, автозагрузку и датчики. Отдельные разделы показывают состояние дисков и характеристики модулей памяти.

Выберите раздел. При первом открытии программа соберёт данные; повторное открытие может показывать сохранённые сведения. **«Обновить»** запрашивает их заново. **«Отменить сбор»** останавливает текущий запрос.

Поиск работает по устройству, параметру и видимому значению. Выделенные строки копируются через **Ctrl+C**. Полное значение длинной строки доступно в подсказке при наведении.

Верхние карточки обновляются раз в две секунды, пока раздел открыт:

- **Процессор** — насколько он занят сейчас.
- **Память** — сколько оперативной памяти используется.
- **Сеть** — текущий объём получаемых и отправляемых данных. Это не максимальная скорость интернета; виртуальные сетевые подключения могут учитываться повторно.

### Личные данные и отчёт о ПК

Серийные номера, имя компьютера, сетевые адреса, пути и команды автозагрузки скрыты. Их можно открыть отдельным флажком. Поиск не показывает скрытые значения.

**«Сохранить полный отчёт»** заново собирает все разделы и сохраняет текстовый файл. Разделы собираются по очереди, поэтому время их обновления может различаться. Если отправляете отчёт другим людям, оставьте флажок личных данных выключенным. Автоматической отправки отчётов нет.

### Температуры и драйвер датчиков

Показания читает встроенный LibreHardwareMonitor. Запускать отдельную программу не нужно. В разделе **«Датчики и питание»** значения обновляются примерно раз в две секунды. Минимум и максимум считаются с открытия раздела; после ухода сборщик останавливается.

Для части датчиков процессора, платы и памяти нужен драйвер **PawnIO 2.2.0 или новее**. Кнопка **«Включить датчики процессора и памяти»** (видна в режиме «Для опытных») скачивает официальный установщик, проверяет его и устанавливает драйвер. Нужен интернет. Если требуется перезагрузка, выполните её самостоятельно.

Некоторые показания видеокарты, дисков и батареи доступны без PawnIO. Поддержка зависит от оборудования. Отсутствие показания не означает нулевую температуру или поломку. Температура зоны **ACPI** относится к области устройства и не обязательно является температурой процессора.

Программа не меняет частоты, напряжения, обороты вентиляторов или защиту Windows. Стресс-тестов процессора и памяти здесь нет.

### Состояние дисков — SMART

SMART — встроенные показатели самодиагностики накопителя: например, температура, наработка или счётчики ошибок. Показываются только данные, которые передал диск. Переходник USB, RAID или виртуальный диск может скрывать часть сведений. Обновление — не чаще раза в 30 секунд.

**RAW** — исходное значение счётчика. Его смысл зависит от модели диска. Его нельзя напрямую сравнивать с нормализованным значением или считать общий ноль признаком полной исправности. Для части NVMe-дисков доступен только сокращённый набор показателей.

### Модули памяти — SPD

SPD — сведения, записанные производителем в модуль памяти. Здесь можно увидеть доступные характеристики и задержки DDR4/DDR5, иногда температуру модуля. Это паспортные данные, а не измерение текущего разгона. Программа не записывает SPD и не применяет профили XMP/EXPO.

## X2 Tools → Таймер

1. Выберите действие: **выключение**, **перезагрузка** или **сон**. Сон срабатывает, только если он разрешён в настройках электропитания Windows.
2. Укажите, через сколько **часов и минут** его выполнить.
3. Нажмите **«Запустить таймер»**. Можно выбрать готовый интервал: 15/30 минут или 1/2 часа.
4. В карточке появятся оставшееся время и дата. Пока таймер работает, оставшееся время видно и в меню значка рядом с часами.

Диапазон — от одной минуты до семи дней. **«Отменить таймер»** убирает запланированное выключение до его начала.

Таймер сохраняется в Windows и работает после полного выхода или обновления x2zapret. В момент выключения компьютер должен быть включён, а пользователь — оставаться в системе. Таймер не будит компьютер и не выключает его позже, если время было пропущено из-за сна или перезагрузки.

Программы не закрываются принудительно. Несохранённые документы могут задержать выключение. При удалении x2zapret его собственный таймер удаляется; чужие задачи остаются.

## X2 Tools → Тест диска

Выберите диск и нажмите **«Запустить»**. По умолчанию используется файл 1 ГиБ и быстрый режим. В режиме «Для опытных» можно выбрать размер и режим:

- **Быстрый** — восемь измерений по три секунды.
- **Подробный** — три прохода, по пять секунд на каждое из восьми измерений.

Перед измерениями нужно время на подготовку файла. Размеры на выбор: 256 МиБ, 1 ГиБ или 4 ГиБ. Нужно место под файл и ещё 1 ГиБ запаса. На FAT32 выбирайте размер меньше 4 ГиБ.

### Как читать результат

| Показатель | Что означает |
| --- | --- |
| **Крупные блоки** | Как накопитель обрабатывает большие последовательные объёмы данных |
| **Мелкие блоки** | Как накопитель обрабатывает множество небольших обращений в разных местах |
| **Чтение / запись, МБ/с** | Сколько данных передаётся за секунду. Больше — быстрее |
| **Операций/с, IOPS** | Сколько отдельных обращений к диску выполнено за секунду |
| **Задержка, мс** | Время выполнения одной операции. Меньше — быстрее |
| **P95 в подсказке** | Время, в которое уложились 95% операций в самом медленном проходе |

Технические подписи сохраняются под понятным названием: `SEQ1M Q8T1`, `SEQ1M Q1T1`, `RND4K Q32T1`, `RND4K Q1T1`. SEQ — последовательные блоки 1 МиБ, RND — случайные блоки 4 КиБ. Q — число ожидающих запросов, T1 — один поток. Разная очередь помогает посмотреть диск в разных условиях.

Используется встроенный Microsoft DiskSpd 2.3. Он работает с **новым временным файлом**, а не с вашими файлами. После проверки или отмены временные данные удаляются. За время замера в этот файл могут записываться данные несколько раз, поэтому общий объём записи может быть больше его размера.

Кэш Windows при проверке не используется; кэш самого накопителя работает как обычно. Для сравнения результатов приостановите другие загрузки и копирование. Свободное место, температура, кэш и фоновые программы влияют на итог. Результаты с другими настройками CrystalDiskMark могут отличаться.

Можно свернуть окно и дождаться окончания. Полный выход отменяет проверку с очисткой. **«Сохранить результат»** создаёт текстовый отчёт, в том числе с завершёнными измерениями после отмены.

Если компьютер выключился или программа аварийно закрылась, в корне диска может остаться папка `x2zapret-disk-test-<случайный код>`. После завершения проверки её можно удалить вручную. Если кто-то добавил в неё посторонние файлы, программа не удаляет их автоматически.

## X2 Tools → Датчики

Сверху — четыре плитки: температура процессора и видеокарты, загрузка процессора и занятая память, с оценкой «Норма», «Тепло» или «Перегрев». Нажмите на плитку, чтобы показать этот датчик на графике. Флажок **«Предупреждать о перегреве»** покажет уведомление, если процессор или видеокарта нагреются выше 90 °C; он работает, пока идёт сбор показаний.

Выберите датчик — на графике появятся его показания за последний час. Доступны загрузка процессора и памяти, а также те температуры, напряжения, обороты и другие данные, которые передаёт оборудование.

Обновление запрашивается каждые две секунды, но чтение аппаратных датчиков может занимать дольше. На каждый датчик хранится до 1800 точек; одновременно — до 512 датчиков. После паузы линия графика прерывается.

По умолчанию сбор идёт только в открытом инструменте. Флажок **«Продолжать сбор при переключении вкладок и сворачивании»** оставляет его работающим в других вкладках и рядом с часами. На время тяжёлых операций сбор приостанавливается. Полный выход удаляет историю из памяти.

**«Сохранить таблицу CSV»** (в режиме «Для опытных») оставляет историю в отдельном файле. CSV можно открыть в редакторе таблиц. Заголовки и единицы подписаны по-русски, время указано в UTC, числовые значения — с точкой. Названия оборудования могут содержаться в файле. Если при открытии всё попало в одну колонку, импортируйте файл с кодировкой UTF-8 и разделителем «запятая».

### Предупреждение по датчику

Выберите датчик, включите флажок **«Предупреждать, если значение выше»**, введите число и сохраните. Например, для температуры можно указать 80 — это 80 °C.

Уведомление появится рядом с часами и в журнале. Оно проверяется только во время сбора показаний. Повторное уведомление возможно после снижения и нового превышения значения, не чаще раза в пять минут на датчик. Показ всплывающих уведомлений зависит от настроек Windows.

## X2 Tools → Интернет

### Стабильность связи

В левом поле укажите IP-адрес или домен сервера, например `1.1.1.1` или `example.com`. В правом выберите своё сетевое подключение: рядом с ним указан **шлюз**, обычно это домашний роутер.

Нажмите **«Проверить соединение»**. Программа отправит 30 тестовых запросов серверу и выбранному шлюзу. Сравнение помогает увидеть, на каком участке есть задержки, но само по себе не устанавливает точную причину сбоя.

| Показатель | Как читать |
| --- | --- |
| **Пинг** | Среднее время ответа. Меньше — быстрее |
| **Джиттер** | Насколько меняется время соседних ответов. Меньше — стабильнее |
| **Потери** | Доля запросов, на которые не пришёл ответ |
| **Минимум / максимум** | Самый быстрый и самый медленный полученные ответы |

Некоторые роутеры и серверы ограничивают ответы на такие запросы — **ICMP**. Поэтому потери в тесте не всегда означают потери обычного трафика или обрыв интернета.

После проверки сверху появится вывод: «Интернет в порядке», «Проблема в домашней сети» (обычно слабый Wi-Fi), «Соединение нестабильно» (часто — у провайдера) или «Сервер не ответил».

Флажок **«Показать путь до сервера»** (в режиме «Для опытных») добавляет список промежуточных устройств, до 20 переходов. Звёздочка означает отсутствие ответа на конкретном переходе, а не обязательно неисправность устройства.

### Скорость скачивания и отправки

Нажмите **«Измерить скорость»**. Подробный режим доступен в режиме «Для опытных».
После замера появится оценка: хватит ли скорости для видео, игр и звонков. Для сравнения приостановите другие загрузки.

Программа принимает и отправляет тестовые данные серверу Cloudflare. Ближайший сервер выбирает сам сервис. На другом сервере или маршруте скорость может отличаться: это не гарантия максимальной скорости тарифа.

Быстрый режим использует **до 62 МБ**, подробный — **до 262 МБ** тестовых данных. Плюс расходуется небольшой объём служебного трафика. Проверка запускается только вручную.

Большие значения **Мбит/с** означают более быструю передачу. Время ответа показывается без нагрузки и во время передачи: так можно увидеть, растёт ли задержка, пока канал занят.

Для технического сравнения: это последовательная передача в одном потоке. Размеры блоков увеличиваются до достижения трёх секунд на отдельный запрос или предельного размера. Скорость считается по полностью переданным блокам и времени запросов, включая работу сервера. Прокси Windows не используется.

**«Отменить»** прекращает текущий замер; завершённые результаты остаются. Незавершённая часть отправки может не попасть в счётчик. При недоступном сервере выводится ошибка. **«Сохранить отчёт»** создаёт читаемый текстовый файл с результатами проверок.

Сервер Cloudflare видит ваш публичный IP, как при обычном обращении к сайту. Учётная запись и личные файлы не передаются. [Описание сервиса измерений](https://github.com/cloudflare/speedtest#api-reference).

### Если сайты не открываются

**«Очистить кэш DNS»** удаляет сохранённые Windows адреса сайтов. Это безопасно и часто помогает после смены профиля обхода.

**«Полный сброс сети»** сбрасывает Winsock и настройки TCP/IP — помогает, если VPN или «ускорители интернета» испортили сетевые настройки. Вручную заданные IP-адреса и DNS станут автоматическими; сохранённые сети Wi-Fi и пароли останутся. После сброса перезагрузите компьютер.

### DNS-сервер

Здесь видно, какой DNS сейчас используют активные подключения. Кнопки **Cloudflare** и **Google** устанавливают надёжный публичный DNS, **«Автоматически (как было)»** возвращает настройку от роутера или провайдера. После изменения кэш DNS очищается автоматически. Если включён VPN, он может задавать DNS сам.

## X2 Tools → Место на диске

Кнопки с буквами дисков сверху сразу запускают анализ всего диска; там же видно свободное место.

Укажите диск или папку и нажмите **«Анализировать»**. Можно выбрать папку кнопкой, подняться на уровень выше или открыть вложенную папку двойным щелчком в таблице.

Вверху показываются до 100 крупнейших папок выбранного уровня и их доля от найденного объёма. Ниже — до 100 крупнейших файлов внутри. Выберите строку и нажмите кнопку проводника, чтобы посмотреть объект. Программа сама ничего не удаляет.

Считается размер доступных файлов. Сжатие, служебные данные, ссылки и недоступные папки могут давать отличие от занятого места в свойствах диска. Один файл с несколькими жёсткими ссылками может учитываться повторно. Пропуски отмечаются счётчиком.

Ограничения поиска: до 10 минут, двух миллионов записей и 10 тысяч групп папок. Если отменить поиск или достичь лимита, останется частичный результат — то, что программа успела найти.

### Освободить место

Карточка **«Освободить место»** считает, сколько занимают временные файлы программ и Windows, скачанные обновления Windows, кэш графики DirectX и корзина. Нажмите **«Посчитать»**, отметьте нужное и нажмите **«Очистить выбранное»**. Временные файлы младше суток и занятые другими программами пропускаются, документы и программы не затрагиваются. Удалённое восстановить нельзя.

## Оформление

В **«Настройках» → «Оформление»** можно выбрать тёмную или светлую тему, либо «Как в Windows» — тогда программа переключается вместе с настройкой Windows.

## Где хранятся настройки и что остаётся после удаления

Папка данных: `%ProgramData%\Z-zapret`. Старое имя сохранено для совместимости с прежними версиями; вручную переносить её не нужно.

| Что находится внутри | Для чего |
| --- | --- |
| `settings.json` | Ваши настройки |
| `lists` | Списки сайтов, IP-адресов и исключений |
| `results` | Результаты автоподбора в JSON |
| `logs` | Журнал программы |
| `hosts-backups` | Резервные копии файла hosts |
| `test-recovery.json` | Данные для восстановления после прерванной проверки |

Если обновление Flowseal убрало старый профиль или служебный файл, программа выберет доступную замену и оставит прежние настройки в `settings.json.before-components-update`. Изменённые стандартные списки сохраняются, а новый вариант может появиться рядом с расширением `.upstream`.

При удалении x2zapret отключаются его собственная служба, автозапуск и таймер, убирается его блок hosts. Пользовательские данные и общие драйверы WinDivert/PawnIO автоматически не удаляются: их могут использовать другие программы.

Команды сборки находятся в [BUILD.md](BUILD.md), устройство проекта — в [STRUCTURE.md](STRUCTURE.md), перенос обновлений Flowseal — в [UPSTREAM.md](UPSTREAM.md). Для запуска готовой программы эти инструкции не нужны.

В [старой инструкции Flowseal](../legacy/flowseal/README.md) описаны исходные консольные инструменты. Они поставляются отдельным архивом и не нужны для обычной работы x2zapret.
