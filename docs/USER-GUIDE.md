# x2zapret для Windows

Приложение для Windows 10 22H2 / Windows 11, x64. Версия 0.2.5.
Все профили закреплённого релиза Flowseal и исходные консольные инструменты сохранены.

Единое чёрно-белое оформление в стиле X2AIR. Переключения тем нет.
Логотип предоставлен владельцем проекта. Папка данных, маркеры службы,
задача планировщика и ключ установщика сохраняют прежние идентификаторы
для обновления пользователей версии Z-zapret без потери настроек.
Ссылки на прежнее имя GitHub остаются совместимыми с перенаправлением после переименования.

## Запуск

Установите `x2zapret-Setup-0.2.5-x64.exe` или распакуйте **весь** portable-архив
и откройте `x2zapret.exe`. Установка .NET отдельно не требуется.
Запуск требует прав администратора: движок использует драйвер WinDivert.
В portable-версии рядом с EXE должны оставаться все DLL, JSON, папки `bin`, `lists`.

1. Откройте «Автоподбор» и запустите быстрый тест.
2. При необходимости выберите полный тест или отдельную стратегию.
3. Примените подтверждённую рекомендацию.
4. На главной странице можно включить автозапуск через службу Windows.

Кнопка закрытия сворачивает приложение в трей (настраивается). Команда «Выход»
в меню трея завершает приложение. Обычный запуск движка прекращается при выходе;
установленная служба продолжает работать. Для её отключения нажмите
«Выключить автозапуск». Чужие службы и процессы не удаляются.

Если уже установлена служба `zapret` другой сборки, приложение покажет конфликт.
Откройте `service.bat` прежней сборки и удалите её службу перед миграцией.

## Что проверяют автотесты

- Быстрый режим: до пяти профилей и основные HTTPS-ресурсы.
- Полный: все профили текущего комплекта, HTTP/1.1, TLS 1.2, TLS 1.3 и справочный ICMP.
- DPI: передача 64 КиБ на цели из открытого каталога dpi-checkers.
- До перебора проверяется соединение без обхода; лучшие три подходящих профиля
  проверяются повторно. Прежнее подключение восстанавливается до применения рекомендации.
- Нужны хотя бы один успешный запрос, не менее 80% успешных поддерживаемых
  проверок и успешные обязательные ресурсы. ICMP не влияет на рейтинг.
- DNS, сертификат, TLS-handshake и неподдерживаемый протокол имеют разные результаты.

Эти тесты подтверждают сетевые запросы, а не воспроизведение YouTube, QUIC/HTTP3,
голосовой чат Discord или отсутствие блокировок во всех приложениях.
Некоторые CDN возвращают 403/404 на корневой адрес: для таких целей эти коды
проверяют только достижимость HTTPS-сервера. Отчёт сохраняет HTTP-код и пояснение.
На Windows 10 системный Schannel может не поддерживать TLS 1.3; такой тест пропускается.

Тесты временно останавливают собственную службу без удаления. Для DPI используются
отдельные копии списков с режимом `any`; пользовательские файлы не меняются.
При отмене выполняется восстановление. После аварийного завершения следующий запуск
читает журнал восстановления; самостоятельный дочерний движок завершается Windows Job Object.

## Настройки и данные

В существующей вкладке «Настройки» доступны переключатели запуска приложения
в трее вместе с Windows и автоматического подключения последней выбранной стратегии.
Второй переключатель работает при включённом первом. Обычное открытие программы
не включает подключение автоматически. Задача планировщика запускается при входе
текущего пользователя с повышенными правами, без сохранения пароля. Удаление приложения
удаляет и эту задачу. Автозапуск движка через службу на главной странице — отдельная настройка.

Переключатель «Автообновление» включает проверку стабильных релизов этого форка
при запуске и каждые 6 часов. Проверку можно вызвать вручную. При обнаружении версии
появятся уведомление и кнопка установки; скачивание и установка требуют подтверждения.
Перед запуском установщика проверяются размер и SHA256 файла из GitHub Releases.
Отмена или повреждённая загрузка не запускает установщик. Настройки и списки сохраняются;
на время установки приложение и подключение останавливаются. После установки откройте
приложение через последний шаг мастера. Portable-сборка обновляется через установщик.

Данные находятся в `%ProgramData%\Z-zapret`:

- `settings.json` — настройки;
- `lists` — пользовательские списки и актуальный IPSet;
- `results` — JSON-отчёты;
- `logs` — журнал;
- `hosts-backups` — резервные копии hosts;
- `test-recovery.json` — журнал незавершённой проверки, если она была прервана.

Списки и фейковые пакеты можно менять через настройки. Пользовательские IP добавляются
к списку в режиме `loaded`; обновление IPSet их не стирает.
Обновление hosts заменяет только блок `BEGIN Z-ZAPRET` / `END Z-ZAPRET`, сохраняя другие
записи. Перед изменением создаётся копия. DNS и антивирус автоматически не меняются.
Старые BAT-инструменты вынесены из приложения в отдельный архив. Его сборка описана в [LEGACY.md](https://github.com/Zuya73/x2zapret/blob/main/docs/LEGACY.md).

Удаление приложения отключает его собственную службу и удаляет его блок hosts.
Общий драйвер WinDivert и пользовательские данные автоматически не удаляются.

## Сборка и проверка

Нужны .NET SDK 10 и Windows для запуска GUI/драйвера; ядро тестируется и на Linux.

Подробные команды и требования находятся в [BUILD.md](https://github.com/Zuya73/x2zapret/blob/main/docs/BUILD.md).


Сборка GitHub Actions компилирует приложение, запускает регрессионные проверки,
проверяет синтаксис исходного PowerShell, рендерит интерфейс без запуска драйвера
и собирает portable ZIP и установщик. Готовые файлы находятся в артефакте `x2zapret-Windows-x64`.

Перед стабильным выпуском нужны реальные проверки на Windows 10 и 11:
драйвер, подключение на нескольких сетях, служба после перезагрузки, отмена теста,
закрытие приложения во время теста, восстановление после сбоя, обновление и удаление.
Графический smoke-тест не заменяет проверки драйвера и работы провайдера.

Сборка не подписана сертификатом издателя. SmartScreen может запрашивать подтверждение.
Проверка манифеста обнаруживает повреждение упакованных бинарников; она не заменяет
цифровую подпись издателя. Сравнивайте SHA256 сборок с опубликованными суммами.

Оригинальная документация Flowseal сохранена в [legacy/flowseal/README.md](https://github.com/Zuya73/x2zapret/blob/main/legacy/flowseal/README.md).

## Публикация обновления

Версия задаётся в `Directory.Build.props`. После успешной сборки и проверок main
workflow автоматически публикует стабильный GitHub Release с тегом `desktop-v<версия>`,
установщиком и portable ZIP. Повторная сборка той же версии не заменяет выпущенные
файлы. Изменение EXE в main без опубликованного релиза клиенту не видно. Автообновление учитывает только
стабильные релизы `desktop-v*` с более новой версией, установщиком с ожидаемым
именем и полем `digest` SHA256 в API GitHub. Исходные релизы Flowseal и предварительные
версии не предлагаются пользователям как обновления приложения.

## X2 Tools: выключение по таймеру

Откройте X2 Tools, задайте часы и минуты и нажмите «Запустить таймер».
Доступны быстрые значения 15/30 минут и 1/2 часа. Допустимый диапазон - от
1 минуты до 7 дней. В карточке видны оставшееся время и точная дата выключения.
До начала выключения нажмите «Отменить таймер», чтобы убрать задачу.

Таймер принадлежит текущему пользователю Windows и работает после закрытия
или обновления x2zapret. При повторном открытии состояние восстанавливается
из планировщика Windows. При удалении приложения его собственный таймер удаляется.
Задачи других программ не изменяются.

Выключение не принудительное: несохранённые документы могут его задержать.
Пользователь должен оставаться в Windows, а ПК - быть включённым. Таймер не будит
компьютер и не выполняет пропущенное выключение после сна или перезагрузки.

## Обновление компонентов Flowseal

Версия компонентов видна в настройках. Новые движок, профили и стандартные
списки приходят вместе с проверенной версией x2zapret, через обычное обновление.
Ручной запуск BAT-файлов для этого не нужен.

Пользовательские списки сохраняются. Неизменённые стандартные списки обновляются;
если стандартный файл был изменён вручную или обновлением IPSet, активная копия
сохраняется, а новый файл автора записывается рядом с окончанием «.upstream».
При удалении выбранного профиля или фейка из нового комплекта выбирается
доступная замена, прежние настройки сохраняются в settings.json.before-components-update.
