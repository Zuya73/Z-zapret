x2zapret 0.2.4 для Windows 10/11 x64.

- Плавные переходы между вкладками и появление карточек.
- Анимированный индикатор выбранного раздела в боковом меню.
- Мягкий отклик кнопок при наведении, нажатии и фокусе с клавиатуры.
- Плавные переключатели, прокрутка страниц и заполнение полосы прогресса.
- Сохранение позиции прокрутки и введённых данных при переходе между вкладками.
- Поддержка отключения анимаций через настройки Windows.
- Автоматическая публикация проверенных обновлений в GitHub Releases.

Настройки и пользовательские списки сохраняются при обновлении.
