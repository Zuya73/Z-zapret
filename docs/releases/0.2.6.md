# x2zapret 0.2.6

- В X2 Tools добавлена «Информация о ПК»: 16 категорий оборудования и Windows, поиск и копирование строк.
- Текущая загрузка процессора и памяти, суммарная активность сетевых адаптеров обновляются раз в две секунды, пока раздел открыт.
- Полный текстовый отчёт собирается по запросу. Серийные номера, адреса и личные идентификаторы скрыты по умолчанию; их включение управляется отдельным флажком.
- Доступные внешние WMI-датчики и батарея, явные пояснения для недоступных показаний. Стресс-тестов и бенчмарков нет.
- Таймер выключения, подключение, автоподбор, настройки, обновления и интеграция Flowseal сохранены.

Это обзор доступных Windows данных; полный набор аппаратных декодеров AIDA64 не заявляется.
