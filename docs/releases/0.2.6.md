# x2zapret 0.2.6

- В X2 Tools появилась информация о ПК: 16 разделов оборудования и Windows, поиск и копирование строк.
- Загрузка процессора, использование памяти и сетевой обмен обновляются раз в две секунды, пока раздел открыт.
- Можно сохранить текстовый отчёт о компьютере. Серийные номера и сетевые адреса скрыты по умолчанию; их показ включается отдельным флажком.
- Доступные датчики и сведения о батарее сопровождаются пояснениями. Для неподдерживаемых данных показана причина, а не выдуманное значение.
- Прежние подключение, автоподбор, настройки, обновления и таймер сохранены.

В этой версии не было стресс-тестов или проверки скорости дисков. Раздел показывает сведения, которые предоставила Windows, и не обещает заменить все возможности AIDA64.
