x2zapret 0.2.5 для Windows 10/11 x64.

- Новая вкладка X2 Tools: выключение ПК по часам и минутам, быстрые интервалы,
  обратный отсчёт и отмена.
- Таймер работает после закрытия/обновления приложения и восстанавливается при открытии.
- Выключение не принудительное; задачи других программ не изменяются.
- Подготовлен воспроизводимый импорт стабильных релизов Flowseal с точным commit,
  хэшами, отдельными правилами совместимости и автоматическим PR.
- Количество профилей больше не ограничено 22.
- Неизменённые стандартные списки обновляются, пользовательские изменения сохраняются.
- Замена файлов движка проверяется целиком и откатывается при ошибке.
- В настройках отображается версия компонентов Flowseal.

Текущий комплект Flowseal остаётся 1.10.4. Новые релизы автора будут проходить
проверки перед включением в обновления x2zapret.
