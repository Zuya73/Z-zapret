# x2zapret 0.2.5

- Появился X2 Tools с таймером выключения: часы, минуты, готовые интервалы, обратный отсчёт и отмена.
- Таймер продолжает работать после закрытия и обновления программы. Приложения не закрываются принудительно.
- Подготовлен перенос новых версий Flowseal с автоматическим запросом на слияние и проверками Windows.
- Количество профилей теперь берётся из комплекта Flowseal и не ограничено прежними 22.
- Стандартные списки обновляются, а ваши изменения сохраняются.
- При неудачной замене файлов обхода программа возвращает прежние файлы.
- В настройках видна включённая версия компонентов Flowseal.

Комплект этой версии — Flowseal 1.10.4. Новые файлы автора проходят проверки перед включением в x2zapret.
