# x2zapret 0.2.8

- В X2 Tools добавлена «Скорость дисков» на встроенном Microsoft DiskSpd 2.3.
- Четыре профиля SEQ1M Q8T1, SEQ1M Q1T1, RND4K Q32T1 и RND4K Q1T1 с раздельным чтением/записью, МБ/с, IOPS и задержками.
- Выбор тома, размера файла и быстрого/подробного режима; прогресс, отмена и текстовый отчёт с частичными результатами.
- Только новый собственный временный файл, предварительно заполненный случайными данными. Без обращения к сырым физическим дискам и существующим файлам, с резервом свободного места и очисткой.
- Целостность встроенного движка проверяется по SHA256, установка отдельного драйвера для замера не нужна.
- Таймер, информация о ПК, встроенные датчики, подключение, автоподбор и обновления сохранены.
