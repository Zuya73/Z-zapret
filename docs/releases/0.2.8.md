# x2zapret 0.2.8

- В X2 Tools появился тест скорости диска на Microsoft DiskSpd 2.3.
- Проверяются крупные последовательные и мелкие случайные блоки данных. Чтение и запись показаны отдельно, вместе с числом операций в секунду и задержкой.
- Можно выбрать диск, размер временного файла и быстрый или подробный режим, отменить проверку и сохранить отчёт.
- Проверка использует новый собственный временный файл. Существующие файлы пользователя не используются. Нужен запас свободного места; после завершения выполняется очистка.
- Инструмент проверки уже встроен в программу и проверяется на целостность. Отдельный драйвер для замера не нужен.
- Таймер, информация о ПК, датчики, подключение, автоподбор и обновления сохранены.

Технические режимы: SEQ1M Q8T1, SEQ1M Q1T1, RND4K Q32T1 и RND4K Q1T1. Подробности измерений есть в руководстве.
