# x2zapret 0.2.3

- Нижняя часть окна больше не уходит под панель задач на небольших экранах.
- Размер окна учитывает свободное место на мониторе и масштаб Windows.
- Боковое меню можно прокручивать; добавлена подпись by Zuya.
- Обновление доступно через «Настройки» → «Проверить сейчас».

Настройки и ваши списки сайтов сохраняются. Для ручной установки этой версии используйте `x2zapret-Setup-0.2.3-x64.exe`.
