# x2zapret 0.2.9

- Отдельная проверка доступности Discord / YouTube и контрольных сайтов с подробностями в диагностике.
- Умное переподключение по настройке: подтверждение сбоя, ограничение попыток, проверка запасных стратегий и восстановление исходной.
- X2 Tools: графики датчиков за час, запись в трее, CSV и пороговые уведомления.
- X2 Tools: пинг, джиттер, потери ICMP, сравнение со шлюзом и маршрут.
- X2 Tools: ручной замер скорости интернета до Cloudflare и задержки под нагрузкой.
- X2 Tools: анализ занятого места, крупнейшие папки / файлы и переход в проводник.
- Сохранены информация о ПК, SMART / SPD, тест накопителей, таймер, автозапуск, настройки и пользовательские списки.

Автопереподключение включается отдельно в настройках. Проверки HTTPS не подменяют проверку видео / голоса.
Скоростной тест использует трафик: до 62 МБ в быстром и 262 МБ в подробном режиме без сетевых накладных расходов.
