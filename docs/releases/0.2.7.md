# x2zapret 0.2.7

- Встроенный мониторинг температур, частот, напряжений, мощности, вентиляторов и других доступных показаний. Отдельный LibreHardwareMonitor больше не нужен.
- Текущие, минимальные и максимальные значения за сеанс; опрос раз в 2 секунды только в открытом разделе.
- Отдельные категории SMART / NVMe и SPD-таймингов DDR4/DDR5. Показаны только доступные данные; диски опрашиваются не чаще раза в 30 секунд.
- Кнопка установки официального подписанного PawnIO для датчиков CPU/платы/SPD с проверкой SHA256, размера и подписи. Без отключения защиты Windows и без автоматической перезагрузки.
- Чтение оборудования вынесено в отдельный процесс с тайм-аутом, отменой и автоматическим завершением при закрытии страницы.
- Прежние разделы информации о ПК, внешние WMI-источники, таймер, подключение, автоподбор и обновления сохранены. Стресс-тестов нет.
