# x2zapret 0.2.7

- Температуры, частоты, напряжения, мощность и обороты доступных вентиляторов теперь читает встроенный сборщик. Запускать отдельный LibreHardwareMonitor не нужно.
- В открытом разделе показаны текущие, минимальные и максимальные значения с начала сеанса.
- Добавлены показатели самодиагностики дисков SMART/NVMe и характеристики памяти DDR4/DDR5 из SPD. Данные дисков обновляются не чаще раза в 30 секунд.
- Появилась кнопка установки официального драйвера PawnIO для части датчиков процессора, платы и памяти. Файл проверяется перед установкой. Защита Windows не отключается, перезагрузка автоматически не запускается.
- Чтение оборудования выполняется отдельно от окна программы. Его можно отменить; при закрытии раздела сбор останавливается.
- Прежние разделы ПК, внешние источники датчиков, таймер, подключение и обновления сохранены. Стресс-тестов нет.
