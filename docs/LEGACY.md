# Консольные инструменты Flowseal

Основной способ запуска x2zapret - `x2zapret.exe` и его графический интерфейс.
Он напрямую управляет движком, службой, диагностикой и автоподбором стратегий.

23 исходных BAT-файла и помощники сохранены в `legacy/flowseal`:
22 профиля `general*.bat` и меню `service.bat`. Они нужны для сверки
импортированных параметров, обновления профилей из upstream и отдельного
консольного запуска. Исходные файлы оставлены без изменений.

## Как получить рабочий консольный комплект

На Windows с Python и PowerShell, из корня репозитория:

```powershell
./build/package-legacy.ps1
```

Скрипт создаёт `artifacts/Flowseal-legacy-tools-1.10.4.zip`: исходные BAT,
помощники, `bin`, `lists`, `.service`, лицензии и оригинальную инструкцию.
Распакуйте архив целиком и следуйте его README.

Каталог `legacy/flowseal` внутри исходников не является самостоятельной
установкой: общие бинарники и начальные списки хранятся в `vendor` и `resources`.
Сборка добавляет их в архив. Сценарии прямо из исходников запускать не нужно.
Архив не содержит GUI x2zapret; консольные инструменты и приложение управляют
одной службой `zapret`, поэтому перед сменой способа управления остановите
движок и отключите собственную службу в используемой сборке.

Прежние workflow и настройки upstream-бота сохранены как справочные файлы
в этом же разделе. В GitHub Actions они не исполняются.
