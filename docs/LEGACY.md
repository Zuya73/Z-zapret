# Старые консольные инструменты Flowseal

Для обычной работы x2zapret запускайте **`x2zapret.exe`**. Он сам управляет подключением, автоподбором и своей службой Windows. Запускать BAT-файлы вместе с ним не нужно.

Слово **legacy** в именах папок и архивов означает прежние консольные инструменты: профили `general*.bat`, меню `service.bat` и помощники. Они сохранены для сравнения с оригиналом, переноса новых профилей и отдельного запуска без графического окна.

## Как получить готовый комплект

На странице выпуска может быть отдельный архив `Flowseal-legacy-tools-<версия>.zip`. Распакуйте его целиком и следуйте приложенной инструкции Flowseal.

Чтобы собрать такой архив самостоятельно, на Windows с Python и PowerShell выполните из корня репозитория:

```powershell
./build/package-legacy.ps1
```

Результат появится в `artifacts`. В него входят BAT-файлы, помощники, `bin`, `lists`, `.service`, лицензии и исходная инструкция. На включённой версии Flowseal 1.10.4 это 22 профиля и меню `service.bat` — всего 23 BAT-файла верхнего уровня.

## Почему не стоит запускать BAT прямо из исходников

Папка `legacy/flowseal` в репозитории не является готовой установкой. Общие файлы программы и начальные списки лежат отдельно, в `vendor` и `resources`. Сценарий сборки добавляет их в рабочий архив.

Графическая программа x2zapret в этот консольный архив не входит. Оба варианта могут управлять службой с именем `zapret`. Перед переходом с одного на другой остановите обход и отключите его фоновое подключение в прежнем варианте.

Прежние процессы GitHub Actions и настройки бота обновлений тоже оставлены в этой папке для справки. Они не запускаются в нашем репозитории.
