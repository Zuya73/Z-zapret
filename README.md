# x2zapret

**x2zapret помогает настроить обход ограничений для Discord и YouTube на Windows 10/11 x64.** Программа сама проверяет готовые профили подключения и предлагает подходящий для вашей сети. Рабочий профиль можно включать одной кнопкой.

Текущая версия — **0.2.11**. Оформление — X2AIR, автор приложения — **by Zuya**.

[Скачать программу](https://github.com/Zuya73/x2zapret/releases/latest) · [Инструкция](docs/USER-GUIDE.md) · [Что изменилось](docs/releases/0.2.11.md)

## Как начать пользоваться

1. На странице загрузки скачайте установщик `x2zapret-Setup-0.2.11-x64.exe` и запустите его.
2. Если Windows спросит разрешение на запуск, нажмите **«Да»**. Оно нужно для работы сетевого драйвера.
3. Откройте **«Автоподбор»** и нажмите **«Начать проверку»**. На время проверки интернет может ненадолго прерываться.
4. После проверки нажмите **«Включить рекомендованный профиль»**.
5. Откройте Discord или YouTube и проверьте нужные вам функции: например, голосовой чат или воспроизведение видео.

Профиль — это готовый набор настроек обхода. Профиль, который работает у одного провайдера, может не подойти другому. Если подключение перестало работать, повторите автоподбор.

### Можно ли запустить без установки?

Да. Скачайте архив `x2zapret-0.2.11-win-x64.zip`, **распакуйте его целиком** и откройте `x2zapret.exe`. Не переносите EXE отдельно от остальных файлов.

Готовый `x2zapret.exe` есть и **в корне этого репозитория**. Чтобы воспользоваться им, скачайте репозиторий целиком через **Code → Download ZIP** и распакуйте. Папки `vendor` и `resources` должны остаться рядом с EXE. Собирать проект и отдельно устанавливать .NET не нужно.

## Что умеет программа

| Раздел | Для чего он нужен |
| --- | --- |
| **Обзор** | Включить или отключить обход, увидеть ответы сервисов и настроить фоновое подключение |
| **Автоподбор** | Проверить профили и найти подходящий для вашего интернета |
| **Профили** | Выбрать готовый набор настроек вручную |
| **Диагностика** | Проверить файлы программы, службы Windows и возможные конфликты |
| **Настройки** | Включить запуск с Windows, восстановление подключения и поиск обновлений; изменить списки сайтов |
| **Журнал** | Посмотреть действия программы и сообщения об ошибках, сохранить их в файл |
| **X2 Tools** | Посмотреть сведения о ПК и воспользоваться дополнительными инструментами |

### Дополнительные инструменты X2 Tools

Инструменты собраны в четыре группы. После каждой проверки сверху показывается короткий вывод простыми словами, а подробные цифры — ниже.

- **Компьютер → Сведения** — процессор, память, видеокарта, накопители, Windows и другие сведения. Личные данные скрыты по умолчанию.
- **Компьютер → Датчики** — графики температуры, нагрузки и других доступных показаний за последний час, предупреждения о превышении.
- **Диски → Скорость** — скорость чтения и записи и вывод: быстрый SSD, обычный SSD или жёсткий диск. Проверка использует собственный временный файл.
- **Диски → Место** — размеры папок и крупнейшие файлы. Инструмент помогает найти, что занимает место; сам ничего не удаляет.
- **Интернет** — стабильность связи и подсказка, где проблема (домашняя сеть или провайдер), скорость до Cloudflare, **очистка кэша DNS и сброс сети**, а также **выбор DNS-сервера** (Cloudflare, Google или автоматически).
- **Таймер** — выключение компьютера через заданное число часов и минут. Таймер работает и после выхода из программы.

Редко нужные возможности — размер и режим теста диска, путь до сервера, подробный замер скорости, экспорт CSV и установка драйвера датчиков — открываются значком шестерёнки справа от вкладок («Для опытных»).

Подробности и объяснение показателей — в [руководстве](docs/USER-GUIDE.md).

## Запуск с Windows и работа в фоне

В **«Настройках»** можно включить запуск программы вместе с Windows. Значок появится рядом с часами; по желанию обход включится автоматически.

**«Фоновое подключение» на странице «Обзор» работает отдельно.** Оно запускает модуль обхода как службу Windows: подключение может работать даже после полного выхода из x2zapret.

Обычное закрытие окна оставляет значок рядом с часами, если включена соответствующая настройка. Для полного выхода нажмите правой кнопкой на значок и выберите **«Выход»**.

## Обновления

Откройте **«Настройки» → «Проверить сейчас»**. Если новая версия доступна, нажмите **«Скачать и установить»**. Можно включить автоматический поиск обновлений — при запуске и каждые 6 часов. Программа спросит разрешение перед скачиванием и установкой.

Перед установкой проверяется, что файл загружен со страницы x2zapret и совпадает с опубликованным. На время обновления программа и обход останавливаются. Настройки и ваши списки сайтов сохраняются.

Обновление файлов в ветке `main` само по себе не создаёт обновление для клиента: для этого публикуется отдельная версия на [странице загрузки](https://github.com/Zuya73/x2zapret/releases).

## Если что-то не работает

1. Убедитесь, что интернет работает без x2zapret.
2. Повторите автоподбор, при необходимости выбрав полный режим.
3. Откройте **«Диагностику»** и нажмите **«Проверить систему»**.
4. Если используете другую программу обхода, сначала отключите её подключение. Два экземпляра zapret могут мешать друг другу.
5. Сохраните журнал и результаты проверки, если нужна помощь с ошибкой.

Статус «Обход включён» означает, что запущен модуль обхода. Ответы сайтов проверяются отдельно. Эти проверки не гарантируют работу голосового чата, воспроизведения видео или всех способов передачи данных.

## На чём основан проект

x2zapret использует открытый движок [zapret](https://github.com/bol-van/zapret) и готовые профили [Flowseal](https://github.com/Flowseal/zapret-discord-youtube). В приложении сохранены все профили включённой версии Flowseal. Это самостоятельное приложение, а не официальный выпуск Flowseal.

Пользовательские данные находятся в `%ProgramData%\Z-zapret`. Старое имя папки сохранено для совместимости: переносить настройки вручную не нужно.
